# 海斗战术室 · Hex Mayhem Lab

版本：v1.2 · 完整英雄池与 GitHub Pages；初始资料库截至 2026-11-19（官方 26.23 版本，部分推荐仍基于 26.22 数据）。

一个可自行维护的**海克斯大乱斗英雄出装与局内强化选取网站**。包含全部 173 位英雄、原有 51 条初始路线，支持针对不同强化选择不同流派、记录实测与导出 JSON。初始出装包含经验性打法与待验证方案，**新增的 148 位英雄不提供未经证实的默认配装。不是实时胜率平台**，也不隶属 Riot Games。

## 启动与发布

- **本地运行：** 下载「海斗战术室-单文件版.html」，双击打开；或者将这份源码保存在同一目录后打开 `index.html`。
- **上线 GitHub Pages：** 阅读 [DEPLOY.md](DEPLOY.md)。已包含 `.github/workflows/pages.yml` 和 `tests/smoke.cjs`，可以在仓库启用 GitHub Actions Pages 后自动部署。
- **页面图片：** 使用 Riot Data Dragon 在线 CDN，断网时会显示中文占位。

## 功能

- 173 位英雄（25 位已有方案，148 位待补配装），51 条初始流派；可编辑核心/备选强化、出装顺序、装备替换、适用场景与依据。
- 英雄检索、常用英雄收藏、定位筛选、全站搜索。
- 三选一强化的流派匹配工具（核心 +40、备选 +15 的**自定义匹配分，不是胜率**）。
- 新增英雄、编辑/复制流派、保存对局日志和自己的实战经验。
- 个人数据只存于当前浏览器 localStorage，支持 JSON 导入/导出。
- PC/手机自适应布局，Ctrl+K 搜索、G 返回总览。

## 数据迁移注意

**本地版与网页版的数据不会自动同步！** 第一次切换线上网址之前，请先在旧版「数据管理 → 导出 JSON」，在网页版「数据管理 → 导入 JSON」。清除网站数据或换设备会丢失未备份数据。

## 英雄池升级（2026-11-19）

- 新增 `roster.js`：在不改变 `localStorage` 个人数据结构的前提下补齐当期 **173 位英雄**，包括永恩 `Yone`、Locke、Zaahen 等。
- 内置离线中文英雄名和主定位；网页可联网时使用 Riot 官方 Data Dragon `16.23.1` 的 `zh_CN/champion.json` 补充并校准称号及定位，缓存官方数据用于下次打开。
- 原有 25 位英雄及其 51 条预设流派不改写；其余英雄初始为「暂无方案」，支持按需添加流派，避免假装有胜率和攻略。
- 英雄库增加「已有攻略 / 待完善」筛选。旧版浏览器收藏、个人自定义流派与战绩均沿用原存储键，不主动重置。
- 本站展示《英雄联盟》标准英雄池，不代表所有英雄在海克斯大乱斗每期都可选。
